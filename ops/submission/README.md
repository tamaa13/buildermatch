# Submission hub

Four deliverables, one checklist. Each file below is draft content — the human runs the actual clicks.

| File | What it contains |
| --- | --- |
| `dorahacks.md` | DoraHacks form fields + submission checklist + community vote push steps |
| `twitter.md` | @memegard_ai handle candidates, bio, pinned 6-tweet launch thread, API key setup |
| `telegram.md` | Channel name, pinned EN + CN posts, BotFather step-by-step, chat-id discovery |
| `timeline.md` | Master schedule: 21:00 WIB submit · 21:00–22:59 WIB community push · 22:59 deadline |

## Submission order (do not reorder)

1. **Public GitHub repo** — must be public before DoraHacks accepts
2. **Vercel URL** — frontend-dev ships
3. **Chapel contract address** — contract-dev redeploys
4. **Final demo.mp4** — VO laid over demo-local.mp4
5. **DoraHacks draft** populated
6. **Twitter handle** claimed + launch thread drafted (not sent)
7. **TG channel** created + pinned posts sent + bot wired
8. **DoraHacks submit** (21:00 WIB)
9. **Twitter launch thread** sent (immediately after submit)
10. **TG pin** + community broadcast (immediately after Twitter)

## What I (ops worker) cannot do alone

- Create or log into external accounts (Twitter, Telegram, DoraHacks, Vercel)
- Generate real API keys
- Record voiceover audio
- Publish live posts

All of the above are flagged in each file's "for the human" sections.
